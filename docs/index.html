          02
          
Preserve uncertainty

          

            Missing or ambiguous evidence stays in review. It is never silently
            upgraded to a pass.
          

        

        

          03
          
Minimize data

          

            The protocol needs evidence for a claim—not identity, biometrics,
            or a surveillance feed.
