# Contributing

The project is experimental. Small, falsifiable contributions are more useful
than large framework proposals.

Good first contributions include:

- a lesson contract from a second domain;
- a case the current schema cannot represent;
- a privacy or ambiguity problem in an example;
- a validator or accessibility improvement;
- evidence that a field is unnecessary.

Before proposing a new field, include:

1. the bounded learning claim;
2. the evidence that cannot currently be represented;
3. the smallest schema change that would represent it;
4. a synthetic example with no personal data.

Do not submit real learner records, credentials, packet captures containing
private traffic, API keys, or proprietary customer material.

By contributing, you agree that your contribution is licensed under MPL-2.0.
